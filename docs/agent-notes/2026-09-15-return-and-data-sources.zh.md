# Agent Note：按当前份额计算收益与使用公开基金数据

Status: implemented

[English](2026-09-15-return-and-data-sources.md) | 中文

## 问题

当前持仓记录只包含账户、基金代码、已确认份额和持仓平均成本单价，不包含申购、赎回、分红、红利再投资、结算调整或平台费用。因此，插件必须区分可以从当前份额测算的值和必须依赖交易账本的收益。

不同基金类别的披露口径也不相同。普通基金在交易日后公布单位净值，并可能提供盘中估值。货币基金公布每万份收益和七日年化。人民币份额 QDII 的净值与估值可能对应不同日期和海外市场区间。

## 决策

Host 使用十进制定点计算，从当前已确认份额计算全部金额。输入、存储值、Remote 值和工具结果使用十进制字符串；仅 Client 展示时舍入。

普通基金只有在估值的基准值、基准日期与已存储净值一致，并且日期间隔能确认一个普通交易区间时才生成当日估算收益。周一估值可以使用前一个周五。更长的节假日间隔保持不可信，因为只凭日历日期无法确定实际收益区间。同一日期净值公布后，已公布净值成为当日主收益和估值价格，已保存估值继续用于对照。

QDII 估值始终是参考变动，而非今日收益。插件展示估值日期、时间、基准净值日期和变动，但不计入当日合计。QDII 已公布收益属于其净值日期，只有该日期等于今日时才进入今日合计。

货币基金使用已公布的每万份收益：`份额 / 10,000 × 每万份收益`。它不生成盘中估值，也不把七日年化换算为当日收益。在支持的人民币单位份额为 1 元口径下，市值等于已确认份额。没有交易账本时，插件不会自动增加份额。

接口中的分红拆分字段，或已公布收益率与原始净值差的明显不一致，会把该日期标记为需要核对。插件停止计算该日收益。持仓浮盈仍是当前成本与价格的比较，并单独标注。

组合汇总只包含收益日期等于组合日期的有效当日结果。缺失、延迟、跨日、未验证或需要核对的持仓保持缺失，不贡献零值。

## 数据源

Host 只向公开只读接口发送六位基金代码。新浪 `hq.sinajs.cn` 提供参考估值；天天基金搜索接口校验精确资料，`f10/lsjz` 提供已公布净值或每万份收益。这些接口属于非官方集成依赖，不承诺可用性和兼容性。

全部响应都作为数据解析。新浪赋值文本经 GB18030 解码后必须精确匹配一条带引号赋值，不执行脚本。插件校验 JSON、HTTP 状态、类别、单位、日期、十进制数值、重复项和未来记录。重定向、HTML 页面、空结果、异常字段、超时和限流均视为失败。

同一基金代码跨账户共用一个进程内刷新 Promise 和一个持久行情记录。基金资料、净值和估值分别使用不同缓存时间。手动刷新绕过过期判断，但仍遵守单代码十秒最短尝试间隔。提供方失败时保留以前带日期的数据并记录错误，其他代码继续刷新。卸载会取消提供方请求、等待共享任务结束，然后关闭 SQLite。

## 考虑过的方案

**根据平均成本和当前份额推断准确到账收益。** 不采用。记录缺少分红、费用、结算和再投资信息，该结果会声称插件并不拥有的数据。

**使用七日年化计算货币基金当日收益。** 不采用。七日年化是滚动年化指标，不是该日到账收益。

**把 QDII 估值变动当作今日收益。** 不采用。现有字段无法确认海外估值区间与用户本地日期的对应关系。

**执行提供方 JavaScript 或抓取渲染网页。** 不采用。精确文本和 JSON 解析可缩小并测试可接受输入，并避免执行远程代码。

## 影响

面板会展示部分合计、明确日期和仅供参考的值，而不是制造虚假精度。计算适合观察当前风险敞口和指示性日内变动，但不能与平台对账单核对。未来交易账本功能必须使用独立数据模型，不得把这些记录重新解释为历史交易。
