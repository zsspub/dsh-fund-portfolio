# dsh-fund-portfolio

[English](README.md) | 中文

为 DeepSeek Harness 提供基金持仓管理。按账户录入基金代码、已确认的当前份额和持仓平均成本单价，然后在原生右侧面板或 Agent 工具中查看盘中估值、已公布收益、持仓市值、浮盈和理论再平衡结果。

> 收益和再平衡均按当前录入份额与行情测算，不是交易账本、到账对账单、可成交价格或投资建议。

## 要求

- DeepSeek Harness `0.1.6-alpha.1`
- Node.js `^22.19.0 || >=24.0.0`
- 使用支持右侧面板的 Web profile

插件支持普通人民币场外公募、人民币份额 QDII 和单位份额为人民币 1 元的普通货币基金。不支持外币换算、场内成交价、申购赎回还原或历史到账收益核算。基金类别来自提供方资料，并采用保守判断；不支持或含义不明确的产品会被拒绝，而不是猜测。

## 安装

使用固定 GitHub 提交安装，以便 DSH 直接使用仓库中提交的构建产物：

```sh
dsh plugin --profile web add github:zsspub/dsh-fund-portfolio#<commit-sha>
```

重启 profile 并刷新浏览器，然后从侧栏底部打开**基金**。该命令只修改指定 profile；插件不会编辑其他 profile。

本地开发安装：

```sh
pnpm install --frozen-lockfile
pnpm run build
dsh plugin --profile web add /absolute/path/to/dsh-fund-portfolio
```

## 使用

1. 点击**账户管理**按钮，在弹窗中新增账户，然后关闭弹窗。
2. 点击**新增持仓**打开弹窗，输入六位基金代码并点击**查证基金**。
3. 确认返回的名称和类别，再输入已确认份额与持仓平均成本单价。
4. 保存后，可见面板会立即刷新，并每 60 秒刷新一次；隐藏标签页后停止轮询。
5. 切换到一个具体账户，点击**目标占比**，为该账户全部现有基金设置合计精确为 `100%` 的目标。

使用**全部账户**或各账户页签，同时筛选持仓和全部汇总；页签支持方向键切换。新增持仓默认使用当前账户。一个账户只能有一条相同基金持仓，请点击**编辑**在弹窗中修改其当前份额或成本，无需离开持仓列表。同一基金可存在于多个账户，并共用一次匿名行情刷新。

删除账户和持仓前必须显式确认。账户清空持仓后才能删除。编辑携带记录版本；过期面板或 Agent 调用会被拒绝，需要先刷新。

## 目标仓位与理论再平衡

目标占比按账户分别保存，仅覆盖该账户已经存在的基金。目标 `0%` 表示理论上卖出全部持仓；当前版本不支持预设尚未持有的基金或现金仓位。

| 指标 | 规则 |
| --- | --- |
| 当前占比 | 单只基金当前市值 ÷ 账户当前总市值 |
| 目标市值 | 账户当前总市值 × 目标占比 |
| 理论调整金额 | 目标市值 − 当前市值 |
| 理论调整份额 | 理论调整金额绝对值 ÷ 当前采用价格 |

只有以下条件全部满足时才生成建议：已选择单个账户、每只基金都设置了目标、目标合计精确为 `100%`、每只基金都有大于零的当前市值。否则面板只显示配置或行情缺失状态，不将缺失值当作零，也不会自动归一化目标。

正差额显示理论买入，负差额显示理论卖出，精确为零时显示无需调整。任意非零差额都会保留；金额和份额仅在界面展示时舍入到两位，小于 `0.01` 的非零值显示为 `<0.01`。结果未计手续费、申购赎回限制、最低交易额、确认时间和到账时间，不构成可直接执行的交易指令。

## 收益口径

输入、SQLite 与 Remote 中的金额、份额和净值均使用十进制字符串。Host 使用十进制定点计算，仅在展示时舍入。

| 指标 | 规则 |
| --- | --- |
| 持仓成本 | 当前份额 × 持仓平均成本单价 |
| 持仓市值 | 当前份额 × 选用的估值或已公布净值 |
| 当日估算收益 | 当前份额 ×（估值 − 已验证的前一净值），仅计算普通基金的可信单日区间 |
| 已公布收益 | 当前份额 ×（已公布净值 − 前一已公布净值），并标明披露日期 |
| 持仓浮盈 | 当前份额 ×（选用价格 − 持仓平均成本单价） |
| 货币基金公布收益 | 当前份额 ÷ 10,000 × 每万份收益 |

同一日期公布净值后，已公布值成为主收益，最近估值仍保留用于对照。缺失或不可靠的值保持待公布状态，绝不补零。

- **货币基金：**不生成盘中估值。七日年化仅供参考，不能换算成当日收益。由于没有交易账本，插件不会自动增加份额或展示累计到账收益。
- **QDII：**面板分别显示估值时间、净值日期和基准日期。海外收益区间无法可靠推断，因此参考估值变动不会计入今日合计。
- **分红拆分：**接口标记或已公布收益率与原始净值差存在明显不一致时，插件停止计算当日收益并提示人工核对。
- **非交易日及延迟披露：**保留最近有效数据及日期。今日合计只包含收益日期等于组合日期的记录。
- **零成本：**仍展示市值和浮盈，但不计算收益率。

## 行情与隐私

Host 读取：

- 新浪 `hq.sinajs.cn` 的 `fu_<基金代码>` 响应作为参考估值。
- 天天基金搜索接口获取精确基金资料，`f10/lsjz` 获取已公布净值或每万份收益。

这些公开只读接口不是受保证的稳定授权 API。Host 会校验 HTTP 状态、精确基金代码、基金类别、日期、十进制数值、单位和响应结构。新浪响应按 GB18030 文本解码，并作为赋值文本解析；不会执行远程 JavaScript。HTML 错误页、空历史、重复或未来日期、异常字段、重定向、超时和限流均视为失败。

行情请求只包含基金代码。账户名称、份额、成本、数据库内容和备份不会发送到行情提供方。单只基金刷新失败时保留带日期的缓存，不阻塞其他基金代码。

## 存储与备份

SQLite 默认位于 `$DSH_HOME/fund-portfolio/portfolio.sqlite3`。数据库使用 WAL、外键、五秒锁等待、事务、schema 版本和乐观记录版本。高于当前版本的 schema 会被拒绝。卸载插件不会删除数据库。

点击**导入导出**按钮打开菜单：**导出 JSON**直接下载全部账户的版本 2 备份，包含账户、当前持仓、目标占比和已查证基金资料，不包含行情缓存；**导入 JSON**从本地选择 `.json` 文件（不超过 20 MiB），先校验并在弹窗中预览记录及冲突，确认后才写入。版本 1 备份仍可导入，其目标占比会保持未配置。存在冲突时禁止合并，替换必须显式勾选确认并在一个事务内完成。数据库和备份包含真实持仓，不应提交到 Git。

## Agent 工具

| 工具 | 用途 |
| --- | --- |
| `fund_account_list/create/update/delete` | 管理账户；删除使用 DSH 原生确认。 |
| `fund_lookup` | 新增前查证精确基金名称和支持的类别。 |
| `fund_holding_list/add/update/delete` | 使用乐观版本管理当前持仓；删除使用 DSH 原生确认。 |
| `fund_allocation_update` | 原子设置一个账户全部现有持仓的目标占比，要求最新版本且合计精确为 `100%`。 |
| `fund_portfolio_summary` | 刷新一次并返回带日期的结果、覆盖数量、目标配置状态和理论再平衡结果。 |
| `fund_quote_refresh` | 手动请求刷新，仍受单基金十秒最短间隔约束。 |
| `fund_portfolio_export/import` | 导出、预览并显式确认 JSON 导入。 |

工具和面板调用同一个 `ctx.fundPortfolio` Host 服务。工具结果包含采用的价格、日期、份额、计算值、覆盖数量和缺失原因。普通 DSH 工具事件会把结果保存在 Session 日志中，因此历史重放不会重新抓取实时行情。插件不新增 Session 事件类型，也不更改 Session 格式版本。

## 配置

Bundle 提供数据库路径。其他默认值如下：

| 字段 | 默认值 | 含义 |
| --- | --- | --- |
| `busyTimeoutMs` | `5000` | SQLite 锁等待时间。 |
| `refreshIntervalMs` | `60000` | 面板可见时的轮询间隔。 |
| `estimateCacheMs` | `60000` | 估值缓存时间。 |
| `navCacheMs` | `300000` | 已公布净值缓存时间。 |
| `fundCacheMs` | `86400000` | 基金资料缓存时间。 |
| `minRefreshMs` | `10000` | 同一代码两次尝试的最短间隔，手动刷新也适用。 |
| `timeoutMs` | `10000` | HTTP 请求超时。 |
| `concurrency` | `4` | 最大并发行情任务数。 |

需要调整时，在 profile 的 `cordis.patch.yml` 中覆盖 `fund-portfolio` 条目。`databasePath` 必须为绝对路径。卸载时会取消提供方请求、等待共享任务结束，再关闭 SQLite。

## 开发

```sh
pnpm install --frozen-lockfile
pnpm run check
pnpm run artifacts:check
DSH_FUND_LIVE=1 pnpm run test:live
```

普通测试使用固定时钟和 fixture，不访问实时行情。`test:live` 是可选的只读 smoke，使用 `005827`、`000198` 和 `270042`，只校验类别与字段，不固定价格。

Host 与 Client TypeScript 分别编译。构建脚本使用已安装的 DSH 协议声明生成 Typert Host 和 Remote 文件，再生成 DSH 浏览器加载器 Bundle。仓库提交 `lib/` 产物，因此可直接从 GitHub 提交安装，不依赖生命周期构建。

持久设计约束见[收益与数据源决策](docs/agent-notes/2026-09-15-return-and-data-sources.zh.md)。
